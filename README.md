# 多模态AI互动式教学智能体

## 项目简介

本项目是为锐捷网络教育信息化应用场景打造的**多模态AI互动式教学智能体**，旨在解决传统AI教学工具功能碎片化、意图理解浅、课件制作繁琐、流程割裂的痛点，实现教师从事务型制作转向教学设计型创新。

## 核心功能

### 1. 本地RAG知识库模块
- 支持教学类文档向量化、分片、存储、语义检索
- 加载本地专业教学资料，大模型优先结合本地知识库内容生成课件
- 完整实现文本预处理、向量化、相似度检索、知识库问答能力

### 2. 多模态交互式需求输入界面
- 同时支持**文字输入 + 麦克风语音输入**两种教学需求录入方式
- **智能多轮对话澄清**：主动追问教师缺失信息（教学目标、授课时长、知识点、重难点、课堂活动、课件风格、受众年级）
- 多模态文件上传解析：支持PDF、Word、PPT、图片、短视频上传
- 支持教师指定参考素材对应关系

### 3. 教学意图理解与多模态融合模块
- 大模型结构化解析教师对话意图，自动提取：教学目标、知识清单、重难点、授课逻辑、课堂设计、作业设计
- 多模态解析能力：文档文本提取、图片知识点识别、短视频关键帧摘要与内容提炼
- 三重信息融合：**教师意图 + 上传参考资料 + 本地RAG知识库**

### 4. 多模态课件全自动生成引擎
- 自动生成完整标准**PPTX课件**：封面、目录、知识正文页、案例页、互动页、重难点总结页、结尾页
- 自动生成配套**Word详细教案**：包含教学目标、学情分析、教学重难点、教学流程、教学方法、课堂互动设计、随堂练习、课后作业、板书设计
- 拓展创新功能：自动生成**课堂互动小游戏/知识点动态创意**

### 5. 迭代优化 + 预览导出闭环系统
- 网页端实时预览生成的课件内容
- 支持教师自然语言修改迭代：调整顺序、简化内容、增加案例、替换素材、修改风格、增减页面
- AI自动理解修改指令、批量更新课件与教案
- 支持一键导出下载：`.pptx、.docx`，互动动画/小游戏支持HTML5网页格式导出

## 技术栈

- **前端**：HTML5 + CSS3 + JavaScript（原生，轻量化易部署）
- **后端**：Python Flask
- **大语言模型**：OpenAI GPT-4 / 智谱GLM-4（可配置）
- **RAG知识库**：ChromaDB + Sentence-Transformers
- **文档解析**：PyPDF2、python-docx、python-pptx
- **图像识别**：OpenCV + Tesseract OCR
- **视频处理**：MoviePy

## 环境配置

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

复制`.env.example`为`.env`，并配置您的API密钥：

```bash
cp .env.example .env
```

编辑`.env`文件，设置：
- `OPENAI_API_KEY`: 您的OpenAI API密钥（或智谱AI、百度文心等国内API）
- `OPENAI_API_BASE`: API基础URL
- `OPENAI_MODEL`: 使用的模型名称

### 3. 安装Tesseract OCR（用于图片文字识别）

**Windows:**
- 下载安装：https://github.com/UB-Mannheim/tesseract/wiki
- 安装后确保tesseract.exe在系统PATH中

**Linux:**
```bash
sudo apt-get install tesseract-ocr
```

**macOS:**
```bash
brew install tesseract
```

### 4. 安装FFmpeg（用于视频处理）

**Windows:**
- 下载安装：https://ffmpeg.org/download.html
- 添加到系统PATH

**Linux:**
```bash
sudo apt-get install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

## 使用流程

### 第一步：上传教学资料到知识库
1. 点击"知识库管理"
2. 上传PDF、Word、PPT等教学文档
3. 系统自动向量化并存储到本地知识库

### 第二步：输入教学需求
1. 在对话界面输入教学主题（文字或语音）
2. 系统会主动追问缺失信息（教学目标、授课时长、知识点等）
3. 可上传参考文档、图片、视频作为素材

### 第三步：生成课件
1. 确认需求后，点击"生成课件"
2. 系统自动融合教师意图、参考资料、RAG知识库
3. 生成PPTX课件和Word教案

### 第四步：预览与迭代
1. 在网页端预览生成的课件内容
2. 通过自然语言提出修改意见（如"增加案例"、"简化内容"）
3. AI自动理解并更新课件

### 第五步：导出交付
1. 点击"导出"按钮
2. 下载PPTX课件、Word教案
3. 互动小游戏可导出为HTML5网页

## 常见问题

### Q1: API密钥如何获取？
A: OpenAI API密钥在 https://platform.openai.com/api-keys 获取。国内可使用智谱AI（https://open.bigmodel.cn/）或百度文心等替代。

### Q2: 视频处理失败怎么办？
A: 确保已安装FFmpeg并添加到系统PATH。检查视频格式是否支持（mp4、avi、mov）。

### Q3: 图片识别不准确怎么办？
A: 确保已安装Tesseract OCR。可调整图片分辨率和清晰度以提高识别准确率。

### Q4: 知识库检索结果不相关？
A: 调整`.env`中的`CHUNK_SIZE`和`TOP_K_RETRIEVAL`参数，或上传更相关的教学资料。
